===========================================
         УСТАНОВКА И ЗАПУСК ASTRA v0.2
===========================================

1. Установите Python 3.10
   - Скачайте с https://python.org/downloads/
   - При установке ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH".
   - После установки перезагрузите компьютер.

2. Установите Ollama
   - Скачайте с https://ollama.com/download
   - Установите, оставив настройки по умолчанию.
   - Откройте командную строку и выполните:
        ollama pull mistral-nemo
        ollama pull phi3:mini
   - Дождитесь завершения загрузки (модели mistral-nemo ~4.7 ГБ, phi3:mini ~2.4 ГБ).

3. Распакуйте архив Astra_v0.2.zip
   - Рекомендуется распаковать в C:\AstraAI (путь не должен содержать кириллицу).
   - Убедитесь, что в папке есть файлы: ui_main.py, terminal_chat.py, install_deps.bat, run_ui.bat.

4. Установите зависимости
   - Дважды кликните по install_deps.bat.
   - Дождитесь окончания установки (может занять 1-2 минуты).
   - Если появится ошибка, запустите командную строку от имени администратора и выполните:
        pip install requests tzdata pyside6 sounddevice scipy faster-whisper keyboard pygame win10toast numpy

5. Запустите графический интерфейс
   - Дважды кликните по run_ui.bat.
   - Если всё успешно, откроется окно Astra Control Panel.

6. Первоначальная настройка в UI
   - Вкладка "Модели":
        - Основная модель: выберите mistral-nemo (или другую, если скачали).
        - Оркестратор: включите чекбокс и выберите phi3:mini.
        - Нажмите "Сохранить настройки моделей".
   - Вкладка "Профиль личности":
        - При желании отредактируйте файлы character/core_self/*.txt.
        - Нажмите "Сохранить параметры личности".

7. Начните общение
   - Введите сообщение в строку ввода и нажмите "Отправить".
   - Astra будет отвечать, а её память будет сохраняться.

8. Очистка диалога
   - Кнопка "Очистить диалог" на левой панели полностью сбрасывает контекст и начинает новую сессию.

9. Голос и инициативность (опционально)
   - Во вкладке "Системные настройки" можно включить голосовой ввод и автономную инициативность.
   - Для голоса нужен работающий TTS-сервер (например, AllTalk) и микрофон.
   - Инициатива будет писать в чат, если пользователь долго молчит (режим прототипа).

10. Управление памятью
    - Вкладка "Память" позволяет просматривать, редактировать и удалять факты из memory_store.json.
    - Также здесь можно редактировать краткосрочный контекст (conversation_state.json).

11. Возможные проблемы
    - "Ollama не отвечает" -> Убедитесь, что Ollama запущен (иконка в трее или процесс ollama.exe).
    - "Оркестратор не работает" -> В настройках моделей проверьте, что оркестратор включён и выбрана phi3:mini.
    - "Не сохраняется имя пользователя" -> Убедитесь, что в сообщении есть маркеры "я", "меня зовут". Оркестратор пока не идеален.
    - "Ошибка импорта PySide6" -> Установите вручную: pip install pyside6

12. Выход
    - Закройте окно UI или нажмите Ctrl+C в консоли, если запускали из командной строки.
